PCB Placement Multi-Agent POC

Can agents take on part of an engineering design flow? This POC tests it on one step: placing components on a KiCad board, from schematic and confirmed requirements to checked, delivered files.

Architecture

Four agents, and code that keeps them in bounds

A lead agent talks with the engineer and hands out work. The rules that matter are not in any prompt: Python hooks check every tool call, so an agent cannot step outside its role even if it tries.

Comparison

Single agent or multi‑agent?

Alongside this system I built a single-agent Claude Code plugin, run from the Claude CLI. Both got the same schematics, requirements and main model, and both outputs went through the same checks.

Boards passing all checks4 / 4Both approaches, both cases
Single agent's token use~1/4Multi-agent used 3.5–4.6× the tokens and 1.8–2.8× the time
Smaller boards, multi-agent11–21%It tried more board sizes before settling
Issues caught by acceptance0All 4 acceptance runs passed first time
Single-agent plugin Fits better when

The board is small, the requirements are clear, and a person reviews the result carefully. Just as correct here, at a fraction of the cost.

Watch out: it skipped the required engineer review on case 05. The rule lived only in its instructions.
Est. US$1.57–1.75 per case at list price.

Multi-agent system Fits better when

Review must be guaranteed and an audit trail matters, or the board should be as small as possible. Code refuses to deliver until the engineer approves.

Most of the extra cost came from handoffs between the lead and placement agents.
Est. US$3.06–4.87 per case at list price.
