PCB Placement Multi-Agent POC

Can agents take on part of an engineering design flow? This POC tests it on one step: placing components on a KiCad board, from schematic and confirmed requirements to checked, delivered files.

Scope: placement only. Not routing, not manufacturing.

[ Screen recording · 60–90 s, on an open-source KiCad sample board ]

Requirement Q&A → live run status as each agent works → layout preview → a gate rejecting a bad result → files downloaded.

Verification

Don't take the model's word for it

An agent saying “done” is not evidence. Every output is checked by code before it can be delivered.

Schematic–PCB consistencyThe board still matches the schematic.
Geometry checksPlacement meets the spatial rules.
File-hash comparisonDelivered files are the ones that were checked.
