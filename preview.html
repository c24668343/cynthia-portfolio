AR Cues & Perspectives in Remote Drone Operation

Master's thesis, NTHU · Human factors group · Degree exam A+

Designed and built a remote drone control interface on my own, then used it to study which AR cues and viewpoints best support pilots.

  • Developed the AR control interface in C#, overlaying visual cues on the pilot's view during remote operation.
  • Integrated a motorized slide rail into the system to give pilots a third-person view of the drone, combining software and hardware in one working setup.
  • Designed user studies comparing combinations of AR cues and viewpoints, and analyzed eye-tracking data to identify the best viewpoint for each task.
C# Augmented Reality Hardware integration User studies Eye tracking

2023 — 2024

Flight Instrument Layout Optimization

Industry–academia collaboration with NCSIST · Algorithm development

Cockpit instrument placement determines how far a pilot's eyes travel across the panel. The goal was to shorten that distance, reducing cognitive load and improving operating performance.

  • Formulated instrument placement as an optimization problem, with pilot eye-movement distance as the objective.
  • Designed a two-phase solver: exhaustive search to find an initial layout, then a genetic algorithm to fine-tune each instrument's position.
  • Implemented the algorithms in Python and C# as the project's software developer.
Genetic Algorithm Exhaustive search Optimization modeling Python C#
