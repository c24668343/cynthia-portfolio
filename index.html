RunDoodle: GPS-Art Running Route Planning Agent

Personal project · Built with Google ADK, following Matt Pocock's development framework

A multi-agent system that turns a natural-language request (place, distance and shape) into a runnable GPS-art route on real streets, with a map preview and GPX export.

  • Orchestrated intent parsing, shape design, road-network analysis, placement search and evaluation agents in Google ADK, using session state, events and nested loops to carry state across stages and self-correct.
  • Gated quality with a multimodal visual judge, deterministic geometry checks and discrete Fréchet similarity, with bounded retries; if a design falls short, routing stops and a structured failure report is returned.
  • Integrated OSM, Google Routes, OSRM and Google Maps with waypoint limits, chunked requests and fallbacks; a KDTree pre-screens rotation, scale and offset candidates so only the top 3 are routed in the first round.
  • Fixed nested-loop exit signals, evaluation hand-off and closed-route scoring; maintain 213 Python and 16 frontend offline tests.
  • Prototyped an image-to-single-stroke pipeline (skeletonization, graph paths, scale simplification) and ran a blind test of 10 themes × 3 runs comparing AI and human judgments, recording trade-offs as ADRs.

Flight Instrument Layout Optimization

Industry–academia collaboration with NCSIST · Algorithm development

Cockpit instrument placement determines how far a pilot's eyes travel across the panel. The goal was to shorten that distance, reducing cognitive load and improving operating performance.

  • Formulated instrument placement as an optimization problem, with pilot eye-movement distance as the objective.
