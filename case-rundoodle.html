Google ADK Personal project · Jul–Aug 2026

RunDoodle

A multi-agent system that turns a plain-language request (a place, a distance and a shape) into a GPS-art route you can actually run, previews it on a map and exports it as GPX.

[ Screen recording · about 60 s ]

Request typed in → agents working (status shown) → route drawn on the map → similarity score → GPX downloaded. Captions name each stage.

How it works

Five agents, one quality gate

01Intent parsingPlace, distance, shape
02Shape designDraws the outline
03Road networkOSM streets around the area
04Placement searchKDTree pre-screen, top 3 routed
05EvaluationScores the result

Quality gate

Multimodal visual judge Deterministic geometry checks Discrete Fréchet similarity

A failed design is retried a bounded number of times. If it still fails, routing stops and the user gets a structured failure report instead of a bad route.

Pass →

Route on map + GPX export

Fail →

Structured failure report
